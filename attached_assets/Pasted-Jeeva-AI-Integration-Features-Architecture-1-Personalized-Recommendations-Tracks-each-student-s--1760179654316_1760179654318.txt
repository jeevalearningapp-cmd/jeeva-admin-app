Jeeva AI Integration: Features & Architecture
1. Personalized Recommendations
Tracks each student’s practice, strengths, weaknesses, learning style.

Suggests modules, lessons, quizzes, flashcards just-in-time based on analytics.

Uses AI models (from OpenAI, Google Gemini, or custom) for recommendations.

Core table: ai_recommendations with user_id, rec_type, rec_value fields.

2. Adaptive Learning Paths
AI plans each learner’s “next best step” (e.g., which module to do next, what to revise, etc.)

Dynamically updates the route/map as user progresses or struggles.

Core table: learning_paths, storing journey, checkpoints, completed, suggestions.

3. Smart Practice & Remediation
Detects weak topics, auto-generates custom quizzes or flashcard sets (“Practice More” button).

Suggests explanations, extra video, or high-yield content for questions missed.

ML models analyze attempt history and give targeted progress advice.

4. Doubt Solving & AI Chatbot
In-app “Ask AI Doubt Solver” or “JeevaBot” powered by LLM (GPT, Gemini, etc.).

Students can ask concept questions, request explanations, or get hints on specific topics.

Integrates context-aware replies: pulls from Jeeva content/question bank plus generic knowledge.

5. Question Generation & Paraphrasing
AI auto-generates practice questions, paraphrases explanations, or rewrites hints.

Used by admins/content creators to expand the question bank with variety and different levels.

6. Analytics & Progress Visualization
AI summarizes user’s progress, builds “Report Card” and “Study Suggestions.”

Dynamic dashboards for user and parent/coach, highlighting areas for focus.

Technical Implementation
Backend: Supabase as primary DB, with event triggers for new practice attempts, quiz submits, etc.

AI Services: API calls to OpenAI, Gemini, or custom hosted ML for recommendations, question generation, chatbot.

Frontend: React hooks (useAIRecommendations, useChatbot, etc.) fetch context-aware content and actions.

Caching/Optimization: Results cached in DB and TanStack Query for speed and cost control.

Security: AI features strictly scoped to each user/session; only admins can run batch or content-generation.
