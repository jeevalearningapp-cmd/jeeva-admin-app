Step 1: Create localized prices in Stripe (one-time setup)

In your existing Stripe account (no need for Indian account), create one product (e.g., “Premium Monthly”).
Create four separate prices on the same product:
GBP price for UK students (e.g., £25)
EUR price for EU students (e.g., €29)
INR price for Indian students (e.g., ₹2099)
USD price for everyone else (e.g., $30)

Outcome: You now have 4 different Stripe Price IDs that all belong to the same plan.

Step 2: Save all four Price IDs in Supabase

In your Supabase “prices” table, create one row for each of the four prices.
Add a column called country_target with values: GB, EU, IN, GLOBAL.
Outcome: Your database now knows which price to show to which region.

Step 3: Detect the user’s country when the app opens

As soon as the app launches (or when user opens the pricing screen), detect the country using IP address (fastest and most reliable method used by OpenAI).
You can use any free IP-to-country service (ipapi.co, ipinfo.io, cloudflare’s 1.etc).
Outcome: Your app now knows if the user is in UK, EU, India or Rest of World.

Step 4: Show the correct currency and amount on the pricing screen

Based on the detected country:
UK → show £25/month (pull GBP price from Supabase)
EU countries → show €29/month (pull EUR price)
India → show ₹2099/month (pull INR price)
Everywhere else → show $30/month (pull USD price)

Outcome: User immediately sees pricing in their local currency — exactly like ChatGPT does in India.

Step 5: Send the correct Price ID to Stripe Checkout

When user clicks “Subscribe”, your backend looks at the detected country and picks the matching Stripe Price ID from Supabase.
Create the Stripe Checkout Session using only that one Price ID.
If the price is INR, automatically enable UPI.
If the price is EUR or GBP, automatically enable local methods (iDEAL, Apple Pay, .etc).
Outcome: Checkout page shows the exact same currency and amount the user saw on your pricing screen. No surprises.

Step 6: Let Stripe handle taxes automatically

Turn on Automatic Tax in Stripe Dashboard.
Stripe will add:
18% GST for Indian users
20% VAT for UK users
Correct VAT rate for each EU country

Outcome: You stay 100% tax-compliant without doing anything extra.
