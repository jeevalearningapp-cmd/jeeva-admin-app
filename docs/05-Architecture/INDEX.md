## System Design
- Frontend: React + Vite + TypeScript + Material-UI
- Backend: Express.js + Node.js
- Database: Supabase PostgreSQL + RLS
- Auth: Supabase Auth
- Payment: Stripe API
- AI: Google Gemini API
