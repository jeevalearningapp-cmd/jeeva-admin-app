# Mobile App Documentation

## Overview
Complete documentation for the Jeeva Learning Mobile App - the student-facing learning platform with practice MCQs, learning content, mock exams, and AI features.

## Contents
- **OVERVIEW.md** - High-level mobile app architecture and features
- **FEATURES.md** - Detailed feature specifications
- **SETUP_GUIDE.md** - Setup and development guide
- **CHAT_INTEGRATION.md** - JeevaBot AI chatbot integration
- **PUSH_NOTIFICATIONS.md** - Push notification implementation
- **MOBILE_INTEGRATION_GUIDE.md** - Backend integration guide
- **MOBILE_IMPLEMENTATION_CHECKLIST.md** - Implementation checklist

## Core Modules
1. **Practice MCQs** - Free unlimited practice with immediate feedback
2. **Learning Content** - Structured lessons with assessment (80% unlock)
3. **Mock Exams** - Timed exam simulation (3h 45m)
4. **Trial Mode** - 1 free subtopic in Practice + Learning
5. **Payment System** - Stripe one-time subscriptions (₹, £, $)
